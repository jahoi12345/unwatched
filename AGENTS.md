## Development

Dev server: `npm run dev` (Vite, default port 5173).

## Stack

Vite + React + TypeScript, no framework beyond React. Styling is a single
`src/styles/global.css` using CSS custom properties for light/dark theming
(`prefers-color-scheme`). No CSS framework — keep it that way unless asked.

## Documentation

Full documentation: https://vite.dev
